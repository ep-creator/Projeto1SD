## Funcionamento

Gera os segmentos da dezena de |F| (0 a 30), mostrada no HEX1: o dígito vai de 0 a 3. A entrada 31 não ocorre (X) e foi usada para simplificar.

## Equações

Equações implementadas no circuito (`'` = NOT; cada termo é um grupo do mapa-K):

* `aDEZ = R4'R3R1 + R4'R3R2 + R4R3'R2'`
* `bDEZ = 0`
* `cDEZ = R4R3R2' + R4R3'R2 + R4R3R1'`
* `dDEZ = R4'R3R1 + R4'R3R2 + R4R3'R2'`
* `eDEZ = R3R2R1 + R4'R3R1 + R4'R3R2 + R4R3'R2'`
* `fDEZ = R4 + R3R2 + R3R1`
* `gDEZ = R4' + R3'R2'`

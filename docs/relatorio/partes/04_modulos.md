# Projeto dos módulos

Para cada módulo são apresentados o funcionamento, a tabela verdade, as equações (com os mapas de Karnaugh, quando a simplificação se aplica), o circuito projetado no Quartus e a simulação (*waveform*). Nos blocos com muitas entradas, em que a tabela completa teria centenas ou milhares de linhas, é mostrada uma forma compacta e casos representativos. Nas equações, `'` indica NOT, `·` AND, `+` OR, `⊕` XOR e `⊙` XNOR.
